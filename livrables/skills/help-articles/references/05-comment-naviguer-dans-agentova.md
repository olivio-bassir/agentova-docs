Titre: Comment naviguer dans l'application web Agentova
Description: Apprenez à naviguer dans l'application web Agentova, incluant la Page d'accueil, les Automatisations, le Brain AI, l'Historique des conversations, et plus encore.
---
Cet article explique comment naviguer dans notre application web. Elle offre un accès facile aux fonctionnalités principales via le menu latéral gauche.

Pour accéder à l'application web, vous devrez d'abord vous connecter en visitant [app.agentova.ai/login](https://app.agentova.ai/login). La navigation se fait principalement via la barre latérale gauche. Si vous avez des questions sur Agentova ou besoin d'aide, cliquez sur le bouton "Aide" sur le côté droit de l'écran. Ce bouton vous donnera accès au support et aux articles utiles du centre d'aide Agentova.

## Barre de navigation dans l'application web

Le menu de l'application web vous permet d'accéder à :

1. Vos Workspaces (Espaces de travail)
2. Page d'accueil avec tous les agents
3. Brain AI
4. Historique des conversations
5. Affiliation (Programme de parrainage)
6. Paramètres du compte

![IMAGE: Screenshot de la barre latérale avec tous les menus]

Explorons chacun de ces onglets !

## Workspaces

Le premier bouton dans la barre de navigation est le seul coloré et affiche le workspace dans lequel vous vous trouvez. Si vous cliquez sur ce bouton, vous pouvez facilement :

1. Voir la liste des workspaces associés à votre compte
2. Voir le workspace dans lequel vous êtes actuellement
3. Créer un nouveau workspace (payant après le 1er)

Les workspaces séparés ont leurs propres bases de connaissances, connexions d'intégrations et conversations avec les Agents. Les agents ne peuvent pas accéder aux informations entre les Workspaces, ce qui garantit qu'ils ne mélangent pas les informations lors de l'exécution de tâches.

## Page d'accueil

La page d'accueil peut être identifiée par l'icône maison. C'est votre point de départ avec :

* Un chat orchestrateur central
* Les 8 cartes de vos agents
* Le module "Apprendre" sur la droite

![IMAGE: Screenshot de la page d'accueil avec les 8 cartes agents]

### Chat orchestrateur

Au centre de l'écran se trouve un **chat orchestrateur**. Utilisez ce chat pour décrire une tâche. Vous pouvez même joindre du matériel au message pour plus de contexte, et vous serez automatiquement dirigé vers l'Agent le plus qualifié parmi les 8 agents disponibles ! Cette fonctionnalité est similaire à l'envoi d'un message directement à un Agent, mais au lieu de devoir choisir un Agent - c'est décidé pour vous.

### Les 8 cartes d'agents

Pour interagir avec un agent, cliquez simplement sur sa carte pour ouvrir l'interface de chat dédiée.

## Navigation dans la page de chat d'un Agent

Lorsque vous ouvrez un chat avec un Agent, sur le côté gauche de la fenêtre, vous pouvez interagir avec les boutons suivants :

### Boutons de navigation (côté gauche)

* **Bouton "Nouveau chat"** – Cliquer sur ce bouton démarre une conversation fraîche avec l'Agent sélectionné. Cela vous permet de commencer une nouvelle tâche ou sujet sans affecter les conversations précédentes, aidant à garder vos conversations organisées et ciblées.

### Historique des conversations

En bas à gauche de l'écran, vous pouvez trouver toutes les conversations précédentes que vous avez eues avec cet Agent. Les chats sont affichés selon leur date d'interaction. Cela signifie que si vous avez interacté avec un Agent dans un chat plus ancien - il sera déplacé en haut.

### Zone de message

Au milieu de l'écran, vous trouverez une **boîte de message**. Comme le chat orchestrateur, c'est l'espace pour commencer à travailler sur une tâche avec un Agent et lui fournir du contexte. Dans la boîte de chat, vous pouvez trouver le bouton suivant :

* **Icône trombone** - Après avoir cliqué dessus, vous pouvez joindre des fichiers au message que vous enverrez. Cela fournira un contexte supplémentaire à l'Agent.

### Fonctionnalités avancées des agents

Certains Agents disposent de fonctionnalités avancées accessibles via des boutons spécifiques dans leur interface :

* **Charlotte** : Hub Créatif (création de visuels, campagnes, programmation)
* **Arthur** : AutoDM & AutoReply (qualification et closing automatisés)
* **Margot** : Auto-SAV (support client multi-canal)
* **Amandine** : Analyse SEO (génération de rapports PDF)

## Brain AI

Pour accéder au Brain AI dans l'application web, vous devez cliquer sur l'**icône cerveau** dans le panneau gauche. Le Brain AI sert de base de connaissances pour les Agents Agentova. Ils utiliseront le contexte des informations stockées dans le Brain AI pour exécuter des tâches.

Dans l'onglet Brain AI, vous pouvez :

* **Gérer votre workspace** en cliquant sur le bouton "Gérer" au-dessus de la carte du workspace
* **Ajouter des connexions** aux comptes sur d'autres plateformes dans la section "Intégrations"
* **Ajouter, supprimer et modifier des informations** (informations sur votre marque, directives que les Agents doivent suivre, détails personnels, liens de sites web ou même fichiers) sur votre entreprise dans la section "Toute la Connaissance"

### Section Intégrations

Vous pouvez connecter vos applications externes :

* Gmail, Outlook, Yahoo Mail, Apple Mail, Exchange, Mail SMTP
* Instagram, Facebook, Page Facebook, WhatsApp
* LinkedIn
* Slack
* Notion

### Section Connaissance

C'est ici que vous pouvez importer :

* Fichiers (PDF, documents, images)
* Textes et informations manuelles
* Briefs internes
* Documents de votre entreprise

## Historique des conversations

Pour accéder à l'Historique des conversations avec nos agents dans l'application web, vous devez cliquer sur l'**icône bulle de chat** dans le panneau gauche.

Utilisez cet onglet pour accéder à votre historique des dernières conversations avec tous vos agents dans l'ordre chronologique à partir du moment où la conversation a été initialement créée. Vous pouvez cliquer sur les trois points à côté des conversations, en les survolant, pour épingler, renommer et supprimer des chats.

## Programme de parrainage

Agentova dispose d'un programme de parrainage qui vous permet de partager Agentova avec vos amis et d'obtenir 1 mois gratuit chacun après qu'ils se soient inscrits. Pour accéder à l'onglet de parrainage dans l'application web, vous devez cliquer sur l'**icône cadeau** dans le panneau gauche.

Une fois que vous cliquez sur cette icône, vous verrez une fenêtre contextuelle qui indiquera votre code de parrainage et les prochaines étapes !

## Paramètres du compte

Pour accéder aux paramètres du compte dans l'application web, vous devez cliquer sur l'**icône engrenage** dans le panneau gauche. Ici, vous pourrez :

* Mettre à jour les paramètres du compte et les informations de contact (à l'exception de l'adresse email, l'email ne peut être modifié que par le support)
* Changer votre mot de passe
* Voir les informations de facturation et le plan d'abonnement
* Gérer votre facturation et annuler votre abonnement
* Soumettre des demandes de fonctionnalités (Wishlist)
* Obtenir de l'aide
* Se déconnecter

## Module "Apprendre"

Sur le côté droit de la page d'accueil, vous trouverez le module **"Apprendre"**.

Ce module affiche :

* Des vidéos explicatives pour chaque agent
* Des démos montrant comment les utiliser
* Des tutoriels pour tirer le meilleur de l'application
* Des guides pour connecter vos outils
* Des conseils pour organiser votre workspace

C'est un centre éducatif intégré directement dans l'interface pour vous aider à maîtriser Agentova rapidement.

## Résumé

En vous familiarisant avec ces zones clés, vous pouvez naviguer dans l'application web Agentova efficacement et tirer le meilleur parti de ses fonctionnalités. Nous sommes ravis de vous aider à démarrer et à tirer le meilleur parti de votre expérience avec nous !
