# Comment appliquer un code promo

**Apprenez à appliquer un code promo lors de l'achat des produits Agentova et à résoudre les problèmes d'application de code.**

---

Pour appliquer un code promo lors du paiement, vous devez d'abord choisir le plan Agentova auquel vous souhaitez souscrire. Si vous avez besoin d'aide pour décider quel plan vous convient, lisez [notre guide sur les Plans et Tarifs Agentova](#).

---

## Instructions étape par étape

Une fois que vous avez choisi le plan qui vous convient et que vous êtes sur la page de paiement, procédez comme suit :

### Étape 1 : Localiser le récapitulatif de commande

Naviguez jusqu'au **"Récapitulatif de commande"** qui affiche votre plan choisi.

![IMAGE: Screenshot du récapitulatif de commande]

### Étape 2 : Entrer le code promo

Entrez le code promo dans le champ **"Code promo"** en dessous du plan affiché.

![IMAGE: Screenshot du champ code promo]

### Étape 3 : Appliquer le code

Cliquez sur **"Appliquer"** à côté du champ.

✅ **La réduction sera appliquée et vous verrez le nouveau prix !**

![IMAGE: Screenshot du prix avec réduction appliquée]

### Étape 4 : Finaliser l'achat

Terminez l'achat d'Agentova avec la réduction en entrant les informations de paiement demandées et, une fois cela fait, cliquez sur **"Valider"**.

## Dépannage des problèmes d'application de code promo

Il existe des cas où un code promo peut échouer. Identifiez le problème que vous rencontrez et trouvez la solution ci-dessous.

### ❌ Erreur "Le code promo est invalide ou expiré"

Si vous obtenez cette erreur, cela signifie que le code promo entré a expiré ou n'est pas valide.

**Solutions :**
1. Vérifiez que le code a été entré correctement (attention aux majuscules/minuscules)
2. Vérifiez la date d'expiration du code
3. Assurez-vous qu'il n'y a pas d'espaces avant ou après le code
4. Utilisez un code différent
5. Contactez la personne qui vous a donné le code pour vérifier sa validité

---

### ❌ Le code promo est correct mais ne peut pas être appliqué

Si le code promo est correct mais affiche une erreur lors de l'application :

**Solutions :**
1. **Vérifiez les conditions d'utilisation** du code :
   - Certains codes ne sont valables que pour certains plans
   - Certains codes ont un nombre d'utilisations limité
   - Certains codes sont réservés aux nouveaux clients

2. **Essayez un autre navigateur** ou mode navigation privée

3. **Videz le cache de votre navigateur** :
   - Sur Chrome : Ctrl+Shift+Suppr (Windows) ou Cmd+Shift+Suppr (Mac)
   - Cochez "Cookies" et "Cache"
   - Cliquez sur "Effacer les données"

4. **Contactez notre support** : [support@agentova.ai](mailto:support@agentova.ai)

---

### ❌ Le code s'applique mais le prix ne change pas

Si le code semble s'appliquer mais le prix final ne change pas :

**Causes possibles :**
- Le code offre un avantage sur les mois suivants, pas sur le premier paiement
- Le code offre un bonus (ex: mois gratuit) plutôt qu'une réduction immédiate
- Le code a déjà été utilisé sur votre compte

**Solution :** Contactez notre support pour clarifier l'avantage exact du code.

## Types de codes promo disponibles

### 🎁 Réduction en pourcentage
Exemple : **WELCOME20** = 20% de réduction

### 💰 Réduction en montant fixe
Exemple : **SAVE10** = 10€ de réduction

### 📅 Mois gratuits
Exemple : **TRIAL2MONTHS** = 2 mois gratuits

### 🔄 Réduction récurrente
Exemple : **VIP15** = 15% de réduction à vie (tous les mois)

## Programme de parrainage vs Code promo

**Code promo :**
- Utilisable une seule fois
- Réduction immédiate
- Date d'expiration

**Programme de parrainage :**
- 1 mois gratuit par ami parrainé
- Pas de limite d'utilisation
- Vous ET votre ami bénéficiez d'un mois gratuit

## Questions fréquentes

### Puis-je cumuler plusieurs codes promo ?

Non, vous ne pouvez appliquer qu'un seul code promo par commande. Choisissez le code qui vous offre le plus grand avantage.

### Le code promo s'applique-t-il sur tous les plans ?

Cela dépend du code. Certains codes sont spécifiques à certains plans (ex: uniquement plan annuel). Vérifiez les conditions du code.

### Que faire si mon code ne fonctionne pas ?

Contactez notre support à [support@agentova.ai](mailto:support@agentova.ai) en fournissant :
- Le code promo exact
- Le plan que vous essayez d'acheter
- Une capture d'écran de l'erreur
