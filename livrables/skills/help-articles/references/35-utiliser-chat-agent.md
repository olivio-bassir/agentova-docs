# Utiliser le chat de l'Agent

**Découvrez comment utiliser l'interface de chat et les paramètres de conversation.**

---

L'interface de chat est l'endroit où toute la communication se produit avec les Agents d'Agentova. Vous pouvez demander à l'Agent d'exécuter des tâches dans son domaine d'expertise et il retournera la tâche exécutée ou une réponse dans le même chat. Vos conversations sont sauvegardées dans **l'historique de chat** auquel vous pouvez accéder plus tard.

---

## Ouvrir un chat

Vous pouvez ouvrir une salle de chat dédiée à un Agent spécifique à la fois sur les apps mobiles (iOS et Android) et sur l'app navigateur (accessible via desktop et appareils mobiles).

### Ouvrir un chat sur l'app navigateur

Pour ouvrir un chat avec un Agent spécifique dans l'app navigateur, procédez comme suit :

1. Allez sur la **page d'accueil** en cliquant sur l'**icône maison** située dans le panneau latéral gauche. Si vous ne voyez pas l'onglet à cause d'un écran zoomé, cliquez sur les **trois lignes** dans le coin supérieur gauche et vous devriez avoir une liste des onglets possibles.

2. Cliquez sur une **carte d'Agent**.

### Ouvrir un chat sur l'app mobile

1. Allez sur la **page d'accueil** en cliquant sur l'**icône maison** située dans le coin inférieur gauche de l'écran.

2. Cliquez sur le bouton **"Tous les Agents"**.

3. Cliquez sur une **carte d'Agent**.

---

## Naviguer dans l'interface de chat

Bien que nous visions à unifier l'interface de chat et la navigation pour les apps mobiles et navigateur - elles diffèrent minimalement.

### Interface de chat de l'app mobile

Lorsque vous ouvrez un chat sur l'app mobile, vous verrez :

* **L'avatar et le nom de l'Agent**. Cliquer sur le nom vous permettra d'accéder aux **paramètres de conversation personnels** et directives de l'Agent.

* Bouton **historique de chat et activité de l'Agent** dans le coin supérieur droit.

* Un **grand champ de saisie de texte** pour entrer votre propre message décrivant la tâche ou une question pour l'Agent.

* Une **icône trombone** pour joindre un fichier à votre message.

* Une **icône éclair** qui contient toutes les actions rapides de l'Agent, automatisations (si disponibles), et actions suggérées de l'Agent.

* Un **bouton d'enregistrement vocal** qui ressemble à des longueurs d'onde et permet d'enregistrer votre voix et de la transcrire pour l'Agent afin que vous n'ayez pas à taper.

### Interface de chat de l'app navigateur

Lorsque vous ouvrez un chat sur l'app navigateur, vous verrez :

* **L'avatar et le nom de l'Agent**.

* Une **icône roue dentée** qui permet d'accéder aux **paramètres de conversation personnels** et directives de l'Agent.

* Une **icône horloge inversée** qui permet d'accéder à tous les chats précédents avec cet Agent spécifique.

* (Parfois) une **carte de suggestion** en haut sur laquelle vous pouvez cliquer pour déclencher un prompt pré-scripté.

* Pour les Agents qui ont des automatisations - **cartes d'action d'automatisation** au-dessus du champ de saisie de message.

* Un **grand champ de saisie de texte** pour entrer votre propre message décrivant la tâche ou une question pour l'Agent.

* Une **icône trombone** pour joindre un fichier à votre message.

* Une **icône éclair** qui contient toutes les actions rapides de l'Agent.

* Une **icône microphone** qui permet d'enregistrer votre voix et de la transcrire comme message texte pour l'Agent.

## Paramètres de conversation de l'Agent

Dans la salle de chat de n'importe quel Agent, vous pouvez accéder à ses paramètres de conversation personnels qui vous permettent de personnaliser comment l'Agent répond. Ces paramètres seront appliqués uniquement à l'Agent spécifique ; cependant, l'Agent se comportera de la même manière dans tous les workspaces.

### Accéder aux paramètres de conversation personnels de l'Agent

* **Sur l'app mobile :** Cliquez sur le nom de l'Agent en haut du chat.
* **Sur l'app navigateur :** Cliquez sur l'**icône roue dentée** à côté du nom de l'Agent.

---

## Paramètres disponibles

Les paramètres de conversation personnels de l'Agent peuvent ajuster comment l'Agent répond. Paramètres disponibles :

### 🎭 Ambiance (Vibe)
Un curseur allant d'officiel à décontracté qui ajuste le ton de la voix.

### 📏 Longueur du message
Choisissez court, moyen ou long.

### 🗣️ Langage
Boutons qui contrôlent le vocabulaire et le ton, vous pouvez choisir basique, décontracté ou expert. Si vous souhaitez changer la langue dans laquelle l'Agent répond - vous pouvez le faire dans la page de paramètres de votre compte.

### 🔍 Rechercher sur Google (toggle)
Permet à l'Agent de récupérer des informations à jour depuis le web.

### ✍️ Style d'écriture (toggle)
Instruit l'Agent de correspondre au ton de votre contenu existant.

### 📝 Instructions personnalisées
Un champ de texte libre où vous pouvez spécifier des directives supplémentaires. Par exemple, vous pourriez dire "Référence toujours nos valeurs fondamentales ; n'utilise jamais d'emojis."

Ces paramètres s'appliquent par chat de l'Agent et persistent à travers les messages, vous permettant d'affiner le comportement de l'Agent.

## Astuces pour utiliser efficacement le chat

### ✅ Soyez précis
Plus votre demande est claire, meilleure sera la réponse de l'Agent.

**Exemple :**
- ❌ "Aide-moi avec les ventes"
- ✅ "Analyse ce tableau de ventes et identifie les 3 produits les plus vendus ce mois"

### ✅ Utilisez les fichiers joints
Joignez des fichiers, images ou screenshots pour donner du contexte.

### ✅ Ajustez les paramètres
Changez l'ambiance, la longueur et le style selon vos besoins.

### ✅ Activez la recherche Google
Pour des informations à jour (stats, actualités, données récentes).
