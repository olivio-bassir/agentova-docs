# Crédits des Workspaces

**Découvrez les crédits des workspaces Agentova, ce qu'ils sont, comment ils sont utilisés, et plus encore.**

---

Les crédits sont des barres d'énergie qui alimentent les Agents pour effectuer le travail avec [plusieurs modèles IA](https://help.agentova.fr/articles/02-quels-modeles-ia-utilise-agentova). Chaque workspace sous votre compte Agentova a son propre plan et son propre montant de crédits disponibles. Ces crédits ne peuvent pas être transférés vers un autre compte ou workspace, car ils sont liés à un workspace individuel.

**Les crédits sont nécessaires pour que les Agents fonctionnent et utilisent les modèles IA.**

⚠️ Si un workspace n'a plus de crédits, les Agents cesseront de fonctionner.

---

## Utilisation des crédits

Les crédits ne sont utilisés que pour les actions que vous ou votre équipe initiez. Les fonctionnalités en arrière-plan qui améliorent votre expérience globale n'utilisent pas de crédits.

### ✅ Les crédits SONT utilisés quand :

* Vous ou les membres de votre équipe workspace chattent avec les Agents
* Vous ou les membres de votre équipe workspace utilisez les [Actions rapides](https://help.agentova.fr/) des Agents (suggestions de tâches prompt)
* Les Agents répondent ou terminent des tâches dans le chat

### ❌ Les crédits NE SONT PAS utilisés pour :

* Les tâches en arrière-plan
* La configuration des automatisations

## Exemples d'utilisation de crédits

| Action | Crédit utilisé ? |
|---|---|
| Vous avez répondu à une question guidée | ❌ Non utilisé |
| De nouvelles idées quotidiennes ont été générées | ❌ Non utilisé |
| Vous avez envoyé un message de réponse sous l'idée d'un Agent | ✅ Utilisé |
| L'Agent a utilisé une autre app ou service que vous avez connecté (une intégration) | ✅ Utilisé |
| Charlotte a créé des posts hebdomadaires dans l'automatisation Social Media Manager | ✅ Utilisé |
| Un post réseaux sociaux a été planifié et publié | ❌ Non utilisé |
| Vous avez ajouté un snippet ou un fichier au Brain AI vous-même | ❌ Non utilisé |
| L'Agent a sauvegardé des informations ou un fichier dans le Brain AI sur demande | ✅ Utilisé |
| Une image a été générée | ✅ Utilisé |
| L'Agent a envoyé une réponse | ✅ Utilisé |
| L'Agent a envoyé un email en votre nom | ✅ Utilisé |
| L'Agent n'a pas répondu à votre message dans le chat | ❌ Non utilisé |
| Un membre d'équipe chatte avec un Agent | ✅ Utilisé |
| Exécution d'une tâche planifiée | ✅ Utilisé |

## Coût en crédits des différentes actions

| Action | Coût en crédits* |
|---|---|
| Image créée dans le chat | Varie entre 0,4 et 0,6 crédit ; dépend de la qualité de l'image |
| Post réseaux sociaux créé dans le chat | 1 crédit |
| Post réseaux sociaux créé à la demande dans l'automatisation Social Media Manager | 0 crédit |
| Message envoyé dans le chat à un Agent | Varie entre 0,1 et 1 crédit ; plus le fil de conversation est long, plus il utilisera de crédits en raison du cache mémoire. Pour une utilisation optimale des crédits, séparez les différentes tâches dans des chats séparés |
| L'Agent a envoyé une réponse à votre message | 0,1 crédit |
| Emails récupérés de la semaine passée dans le chat | 1 crédit |
| L'Agent a sauvegardé des informations ou un fichier dans le Brain AI sur demande | 0,1 crédit |
| Site web scrapé dans le chat | 0,5 crédit |
| Exécution d'une tâche planifiée | Varie selon la profondeur de la tâche :<br>- 1-5 crédits pour les tâches basiques (génération de texte simple)<br>- 3-10 crédits pour les tâches de recherche (avec recherche web)<br>- 5-20+ crédits pour les tâches complexes (outils multiples, intégrations) |

*Les coûts en crédits sont approximatifs et peuvent varier légèrement en fonction des informations fournies à votre Agent dans le chat.

## Visualiser l'utilisation des crédits du workspace

Vous pouvez voir combien de crédits restants vous avez dans un workspace sur l'app web à [app.agentova.fr](https://app.agentova.fr).

### Accéder à l'aperçu des crédits

Pour accéder à l'aperçu des crédits de votre workspace, procédez comme suit :

1. Assurez-vous d'être dans le workspace dont vous voulez consulter l'utilisation sur [app.agentova.fr](https://app.agentova.fr). Pour vérifier le workspace dans lequel vous êtes, cliquez sur l'icône workspace carrée dans le coin supérieur gauche. Le workspace dans lequel vous êtes sera mis en surbrillance.

2. Ouvrez les paramètres de votre workspace en cliquant sur l'icône roue dentée dans le coin inférieur gauche.

3. Allez dans la section **"Usage & Facturation"**.

💡 Les statistiques de votre utilisation de crédits sur différentes tâches seront bientôt disponibles !

## Informations dans l'aperçu des crédits

Une fois là-bas, vous verrez des informations sur :

* **Crédits restants pour ce mois** : affichés dans le coin supérieur droit de la carte d'utilisation. Ex : 100/250 signifie qu'il reste 100 crédits pour ce mois, se terminant le jour du mois où votre plan a été activé.

* **Crédits utilisés ce mois** : affichés lorsque vous survolez la partie grise de la barre d'utilisation. C'est ce que vous avez consommé jusqu'à présent.

* **Date de réinitialisation des crédits** : sous votre barre d'utilisation. Les crédits sont réinitialisés le jour du mois où vous avez commencé votre abonnement.

* **Plan workspace actuel**

* **Plan de recharge de crédits**

## Plans de crédits des workspaces

Les plans de workspace incluent un nombre prédéfini de crédits chaque mois, selon :

* Où vous vous êtes inscrit (votre fournisseur de paiement) : notre site web, Apple App Store, ou Google Play Store
* Le plan que vous avez acheté

Vous pouvez également acheter des recharges de crédits (Énergie des Agents), à tout moment. Les recharges ont un nombre défini de crédits, ne sont pas remboursables, et ne sont disponibles que sous forme de plans. Vous trouverez la liste complète des plans de recharge disponibles dans votre section "Usage & Facturation".

## FAQ

### Qu'est-ce qu'un crédit ?

Un crédit est une barre d'énergie que votre Agent utilise pour travailler. C'est une unité de mesure pour l'utilisation avancée de l'IA.

### Que se passe-t-il si je n'ai plus de crédits ?

Vos Agents cesseront de fonctionner une fois qu'il n'y a plus de crédits restants. Vous recevrez une notification pop-up une fois que vous êtes à court de crédits et vous pourrez acheter des recharges de crédits pour en obtenir plus.

### Comment puis-je recharger mes crédits ?

Vous pouvez acheter des recharges d'énergie d'Agent comme add-on au plan de votre workspace :

1. Ouvrez les paramètres de votre workspace
2. Sélectionnez "Usage & Facturation"
3. Sous la section "Vos Abonnements", à côté de votre plan actuel étiqueté "Plan Workspace", cliquez sur "+ Ajouter des crédits"
4. Choisissez votre plan de recharge
5. Sélectionnez "Payer maintenant"

### Puis-je obtenir des crédits gratuits ?

Vous obtenez **20 crédits gratuits** lorsque vous créez un nouveau workspace dans votre compte Agentova existant. Gardez à l'esprit que vous devez d'abord avoir un abonnement payant pour créer de nouveaux workspaces avec des crédits gratuits.

### Que se passe-t-il si je n'utilise pas tous les crédits achetés ?

Si vous n'utilisez pas tous les crédits inclus dans vos plans, ils ne seront pas reportés à la prochaine période de facturation et seront réinitialisés à la prochaine date de charge. Vous pouvez demander un remboursement complet pour votre plan workspace si l'achat initial a été effectué dans les 14 derniers jours. Les recharges de crédits ne sont pas remboursables.

### Les crédits non utilisés sont-ils reportés au mois suivant ?

Les crédits non utilisés ne sont pas reportés à la prochaine période de facturation. Ils sont réinitialisés au début de chaque cycle de facturation.

### Puis-je obtenir un remboursement pour les crédits non utilisés ?

Nous n'offrons pas de remboursements pour les crédits non utilisés. Vous êtes éligible à un remboursement complet du plan workspace dans les 7 premiers jours de votre achat. Après ces 7 jours initiaux, vous ne serez pas éligible à un remboursement. Les recharges de crédits ne sont pas remboursables.

### Quand ma limite de crédits mensuelle se réinitialise-t-elle ?

Votre limite de crédits mensuelle se réinitialisera sur une base mensuelle, à la même date et heure que vous avez commencé votre abonnement. Pour une date et heure détaillées, vérifiez votre section facturation.
