## Accéder à Agentova Prompts

1. Ouvrez [https://app.agentova.fr/legacy](https://app.agentova.fr/legacy) et connectez-vous. Contactez le support si vous recevez des erreurs à cette étape.
2. Choisissez **Prompts**
3. Sélectionnez la carte de prompt de votre choix et suivez les instructions sur la page

## Accéder à Agentova Bots

1. Visitez [https://app.agentova.fr/legacy](https://app.agentova.fr/legacy) et connectez-vous. Contactez le support si vous recevez des erreurs à cette étape.
2. Sélectionnez **Voir le Bot** sur le bot que vous souhaitez configurer
3. Suivez le lien dans l'étape 2 du guide de configuration. Cette étape inclura également une vidéo de présentation de la configuration pour ce bot spécifique

---

## Bundle Agentova Max

Les Agentova Bots sont des fichiers JSON de bots prêts à l'emploi téléchargeables, que vous pouvez importer dans make.com, avec un guide de configuration prêt à l'emploi. Ces bots peuvent accomplir des tâches spécifiques selon un calendrier défini.

Pour utiliser les Agentova Bots, vous devez d'abord créer un compte [make.com](http://make.com/). Cela peut être fait gratuitement et Make est gratuit pour jusqu'à 1 000 opérations par mois. Une fois que vous dépassez cela, vous ne payez que pour les opérations que vous utilisez avec Make : [https://www.make.com/en/pricing](https://www.make.com/en/pricing)

De plus, vous devez avoir accès aux crédits API OpenAI pour utiliser le modèle de votre préférence dans la configuration du bot. Les crédits sont disponibles à l'achat sur [https://platform.openai.com/account/billing/overview](https://platform.openai.com/account/billing/overview).
