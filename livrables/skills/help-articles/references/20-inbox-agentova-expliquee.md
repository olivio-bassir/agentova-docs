# Fonctionnalité Idées Agentova (Bientôt disponible)

**Découvrez comment vous pourrez utiliser la fonctionnalité Idées pour recevoir des suggestions quotidiennes des agents.**

---

**⚠️ Note importante :** Cette fonctionnalité est actuellement en développement et n'est pas encore disponible dans Agentova. Cet article décrit comment elle fonctionnera une fois implémentée.

---

Si vous êtes actif dans l'app, vous recevrez des idées de nos agents quotidiennement : 3 agents vous suggéreront des idées dans leur domaine sur comment ils peuvent vous assister dans votre travail—de la création de campagnes marketing uniques à l'utilisation de vos success stories clients pour des articles LinkedIn. Vous trouverez ces idées dans votre Inbox. Voici comment tirer le meilleur parti de cette fonctionnalité :

Tout d'abord, allez dans votre inbox :

Sur l'app navigateur : cliquez sur l'icône inbox dans le panneau latéral gauche, deuxième bouton depuis le haut.

Sur l'app mobile : cliquez sur l'icône inbox dans le panneau inférieur, deuxième bouton depuis la gauche.

Si de nouvelles idées existent, vous verrez une section "Idées" avec 3 idées des Agents Agentova.

Une fois que vous cliquez sur l'idée - vous ouvrirez un chat avec cet agent où il explique ce qu'il suggère de faire.

Si vous souhaitez que l'agent exécute l'idée - vous pouvez lui répondre, voir ce qu'il fait et travailler sur l'idée à partir de là. L'idée sera sauvegardée comme un chat dans l'historique une fois que vous envoyez un message de réponse.

Si vous ne voulez pas travailler sur l'idée - fermez simplement le chat. L'idée et le chat associé ne seront pas sauvegardés dans ce cas.

---

## FAQ

### Combien d'idées sont générées ? À quelle fréquence ?

Les agents génèrent des idées pendant que vous dormez et vous présentent 3 nouvelles idées chaque jour si vous êtes actif dans l'app quotidiennement. Si vous n'êtes pas actif dans l'app pendant plus d'un jour - les idées quotidiennes ne seront pas générées.

### Pourquoi je ne reçois plus 12 idées ?

La fonctionnalité des idées quotidiennes a changé - maintenant, au lieu de 12 idées que vous pouvez faire défiler, vous recevez 3 idées plus personnalisées pour vous.

### Les idées quotidiennes utilisent-elles mes crédits ?

La génération d'idées quotidiennes est une tâche en arrière-plan, car les idées sont générées sans contribution supplémentaire de votre part. Elles n'utilisent pas de crédits sauf si vous interagissez avec l'idée en envoyant une réponse dans le chat.

Utilisez la fonctionnalité Idées pour obtenir de nouvelles perspectives quotidiennement !
