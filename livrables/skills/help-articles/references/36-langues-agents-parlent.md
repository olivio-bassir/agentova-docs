## Comment changer la langue de l'Agent ?

### Méthode 1 : Demander directement dans le chat

Le plus simple ! Dites simplement à l'Agent :

**Exemples :**
- "Réponds-moi en espagnol"
- "Peux-tu me parler en allemand ?"
- "Switch to English please"

L'Agent comprendra et passera à la langue demandée.

### Méthode 2 : Via les paramètres de conversation

1. Ouvrez un chat avec un Agent
2. Cliquez sur l'**icône roue dentée** (navigateur) ou sur le **nom de l'Agent** (mobile)
3. Dans les paramètres, vous pouvez configurer la langue préférée

## FAQ

### L'Agent peut-il traduire du contenu ?

**Oui !** Les Agents peuvent traduire du texte d'une langue à une autre. Il suffit de demander :

**Exemple :** "Traduis ce texte en anglais : [votre texte]"

### Puis-je utiliser plusieurs langues dans le même chat ?

**Oui**, vous pouvez changer de langue en cours de conversation. L'Agent s'adaptera automatiquement.

### La qualité est-elle la même dans toutes les langues ?

La qualité est excellente dans les **langues principales** (français, anglais, espagnol, allemand, italien, etc.). Pour certaines langues moins courantes, la qualité peut varier légèrement mais reste très bonne.

### L'interface utilisateur est-elle disponible en toutes langues ?

Non, l'**interface utilisateur (UI)** d'Agentova est disponible dans un nombre limité de langues. Cependant, les **Agents eux-mêmes** peuvent communiquer dans plus de 100 langues.
