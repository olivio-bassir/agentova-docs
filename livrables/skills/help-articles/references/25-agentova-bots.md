# Agentova Bots

**Que sont les Agentova Bots ?**

---

Lors de l'achat d'Agentova Bots (précédemment disponibles en masse dans le bundle Agentova Max), vous recevrez des fichiers JSON téléchargeables qui peuvent être importés directement dans make.com.

Avec ces fichiers, un guide de configuration avec une vidéo de présentation est fourni, ce qui vous permet de démarrer rapidement votre automatisation.

Chaque bot est conçu pour automatiser une tâche spécifique. Vous êtes libre de personnaliser les scénarios d'automatisation selon vos besoins personnels, mais gardez à l'esprit que notre équipe de support client est qualifiée pour vous assister uniquement avec les configurations de bot d'origine.

---

## Tarification et fonctionnement

Il y a des **frais uniques** pour l'achat des Agentova Bots avec accès à vie, et make.com est gratuit à utiliser pour jusqu'à 1 000 opérations par mois. Une fois que vous dépassez cela, vous ne payez que pour les opérations que vous utilisez avec Make. Vous pouvez trouver les plans tarifaires disponibles pour make.com sur [https://www.make.com/en/pricing](https://www.make.com/en/pricing).

De plus, vous devez avoir accès aux crédits API OpenAI, afin de pouvoir utiliser le modèle GPT de votre préférence dans la configuration du bot. Vous pouvez trouver des informations sur les tarifs OpenAI ici : [https://openai.com/pricing](https://openai.com/pricing)

Si vous avez besoin d'informations supplémentaires ou d'aide pour acheter des jetons API chez OpenAI, nous vous suggérons de les contacter directement.

## Comment accéder aux bots

Pour accéder aux bots inclus dans le bundle Agentova Max, il vous suffit de :

1. Naviguer vers [https://app.agentova.fr/legacy](https://app.agentova.fr/legacy) après vous être connecté
2. Choisir **Bots**
3. Sélectionner **"Voir le Bot"** sur le bot que vous souhaitez configurer
4. Sélectionner le lien dans l'étape 2 du guide de configuration. Cette étape inclura également une vidéo de présentation de la configuration pour ce bot spécifique

Pour vous connecter sur [https://app.agentova.fr/login](https://app.agentova.fr/login), entrez votre adresse e-mail pour confirmer la propriété par e-mail ou utilisez un mot de passe.
