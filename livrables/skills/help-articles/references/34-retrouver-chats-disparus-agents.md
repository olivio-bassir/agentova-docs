# Comment retrouver les chats avec les Agents qui semblent disparus ?

**Retrouvez vos chats manquants avec quelques étapes rapides.**

---

Vos chats peuvent sembler manquants si vous les cherchez dans un autre workspace Brain AI. Bien que l'App Agentova n'offre pas de fonctionnalité de synchronisation en direct — ce qui signifie que votre progression n'est pas mise à jour en temps réel sur plusieurs appareils — rafraîchir la fenêtre de votre navigateur ou redémarrer l'App Agentova sur l'autre appareil devrait suffire pour que votre travail le plus récent apparaisse.

---

## 🤔 Mes derniers chats avec les Agents ont disparu de l'app mobile

Si vous étiez en train de chatter avec votre Agent sur un navigateur et que vous voulez reprendre la conversation dans l'app mobile, vous devrez d'abord **fermer (quitter) complètement l'app mobile Agentova**. Une fois que vous la rouvrez, vos dernières données de chat seront transférées depuis l'app web.

### Sur iOS :

1. Double-cliquez sur le bouton Home ou balayez vers le haut depuis le bord inférieur et marquez une pause au centre de l'écran
2. Balayez vers la droite pour trouver l'app Agentova
3. Balayez vers le haut sur sa carte
4. Rouvrez l'app en appuyant sur son icône sur votre écran d'accueil

**Guide Apple Support :** [https://support.apple.com/en-us/109359](https://support.apple.com/en-us/109359)

### Sur Android :

1. Balayez vers le haut depuis le bas de votre écran jusqu'en haut
2. Si vous obtenez Toutes les Apps, appuyez dessus
3. Balayez vers le haut sur la carte de l'app Agentova
4. Rouvrez l'app en appuyant sur son icône sur votre écran d'accueil ou le menu Toutes les Apps

**Guide Android Help :** [https://support.google.com/android/answer/9079646?hl=en](https://support.google.com/android/answer/9079646?hl=en)

---

### Si vos chats n'apparaissent toujours pas après redémarrage de l'app

1. **Redémarrez votre téléphone** et vérifiez votre historique de chat dans l'app mobile après

2. **Réinstallez l'app mobile :**
   - Désinstallez d'abord l'app
   - Puis réinstallez-la depuis l'App Store ou Play Store
   - Vérifiez l'historique de chat dans votre app mobile

3. **Contactez le support :** Si vos derniers chats ne sont toujours pas là, [contactez-nous](#) pour une aide supplémentaire

---

## 🤔 Mes chats avec les Agents ont disparu de l'app navigateur

Si vous étiez en train de chatter avec un Agent sur l'app mobile et que vous voulez continuer la conversation dans l'app navigateur, **rafraîchissez d'abord l'onglet de votre navigateur**.

### Étapes de dépannage :

1. **Vérifiez le workspace**
   
   Assurez-vous d'être dans le bon workspace Brain AI, car les données des autres workspaces n'apparaîtront pas dans la liste d'historique de chat.

2. **Videz le cache du navigateur**
   
   Si vous ne trouvez toujours pas les chats, vider le cache et les cookies de votre navigateur exclusivement pour la page [app.agentova.fr](https://app.agentova.fr) peut aider.

3. **Essayez un autre navigateur**
   
   Testez de vous connecter avec un navigateur différent (Chrome, Firefox, Safari, Edge)

4. **Mode navigation privée**
   
   Essayez de vous connecter en mode navigation privée/incognito pour vérifier si le problème vient du cache

---

## 😰 Que faire si mes chats sont toujours disparus ?

Si vous avez essayé toutes ces étapes et que vos chats sont toujours disparus, [contactez notre support client](#).

💡 **Astuce bonus :** Évitez de laisser les sessions de chat ouvertes pendant de longues périodes, et fermez-les toujours correctement pour qu'elles soient correctement enregistrées. Cela aide à prévenir les problèmes potentiels à l'avenir.

---

## Checklist de dépannage rapide

### App Mobile → App Web

- [ ] Rafraîchir la page web (F5 ou Cmd+R)
- [ ] Vérifier que vous êtes dans le bon workspace
- [ ] Vider le cache du navigateur pour app.agentova.fr
- [ ] Essayer un autre navigateur

### App Web → App Mobile

- [ ] Fermer complètement l'app mobile (pas juste minimiser)
- [ ] Rouvrir l'app mobile
- [ ] Redémarrer le téléphone si nécessaire
- [ ] Réinstaller l'app mobile en dernier recours

### Cause commune

- [ ] Vérifier le workspace Brain AI (les chats sont liés au workspace)
- [ ] Attendre 1-2 minutes pour la synchronisation
- [ ] Contacter le support si rien ne fonctionne
